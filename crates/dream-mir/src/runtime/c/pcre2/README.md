# Vendored PCRE2 (Dream)

This directory is **PCRE2 10.45** (16-bit library only), vendored so both targets share one
engine:

- **Native C** (`../regex.c` with `-DDREAM_NATIVE`, `dream run`): `SUPPORT_JIT` in
  `config.h` unless `PCRE2_WASM` is defined. JIT uses sljit under [`../deps/sljit/`](../deps/sljit/README.md).
- **wasm32 guest**: `regex.c` + [`SOURCES`](SOURCES) compile with `-DPCRE2_WASM` (no JIT
  sources) through the same wasi-sdk clang pass as every other runtime unit.

Edit `../regex.c` (one wrapper). Native no longer has a second `native/regex.c`.

Licence: see [`COPYING`](COPYING) (upstream PCRE2 BSD). JIT pieces follow sljit’s licence
in `../deps/sljit`.

## How to refresh this vendor tree

1. Download [pcre2-10.45](https://github.com/PCRE2Project/pcre2/releases/tag/pcre2-10.45)
   (source tarball).
2. Copy `src/pcre2_*.c`, `src/pcre2_*.h`, `src/pcre2.h.in` into this directory (keep
   Dream’s `config.h`).
3. Copy sljit from upstream `deps/sljit` into `../deps/sljit/` (see that README).
4. Re-apply Dream `config.h` knobs:
   - `SUPPORT_PCRE2_16`, `SUPPORT_UNICODE`, `HAVE_MEMMOVE` / stdlib + string headers
   - `#ifndef PCRE2_WASM` → `#define SUPPORT_JIT 1`
   - no `SUPPORT_PCRE2_8` / `_32`
5. Native: `dream run` links catalog `shared_c` + `SOURCES` + `native_extra_c` when
   `RuntimeNeed::REGEX` is set (`-DDREAM_NATIVE -DHAVE_CONFIG_H -DPCRE2_CODE_UNIT_WIDTH=16`).
6. wasm32: run regex goldens (`tests/cases/regex_*.dream`) through a wasm32 build.

Do not compile `pcre2_jit_match.c` / `pcre2_jit_misc.c` as their own objects; JIT is
included from `pcre2_jit_compile.c` on native only (`native_extra_c` in the catalog).

`config.h` is checked in (not generated by autotools on the Dream tree).
