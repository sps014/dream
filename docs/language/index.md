# The Dream language

Dream is statically typed and compiles ahead of time to a native binary or to WebAssembly. Memory is managed automatically, and each page below covers one feature with examples you can run.

Badges show where a feature works: **Native** for a desktop executable, and **Browser** or **Node** for WebAssembly. New here? Start with the [language tour](../learn/tour.md).
