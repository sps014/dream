# The Dream language

Dream is statically typed and compiles ahead of time to a native binary or to WebAssembly. Memory is managed automatically by reference counting. Each page below covers one feature, with examples you can run.

Badges show where a feature works: **Native** for desktop executables, **Browser** and **Node** for WebAssembly output. New to Dream? Take the [language tour](../learn/tour.md) first.
