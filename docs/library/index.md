# Standard library

Import the packages you need, such as `import system.collections;`. `Option`, `Result`, and `Math` need no import, and shaders are covered in [GPU and ML](gpu/index.md).

Each guide explains a task with examples. Entries with an **API** link also open the exact public declarations for that package in the [API reference](../reference/api/index.md).
