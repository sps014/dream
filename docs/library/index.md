# Standard library

Dream includes a library for everyday tasks. Import the packages you need, such as `import system.collections;`. A few common types, including `Option`, `Result`, and `Math`, are available without an import.

Each guide explains a task with examples. Entries with an **API** link also open the exact public declarations for that package in the [API reference](../reference/api/index.md).
