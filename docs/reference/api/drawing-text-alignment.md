# Text Alignment

**Import:** `import system.drawing;`

## `TextAlignment`

Alignment of a paragraph within its wrapping width.

```dream
public enum TextAlignment
```

## `Start`

Aligns to the start edge of the text direction.

```dream
Start = 0
```

## `Center`

Centers each line.

```dream
Center = 1
```

## `End`

Aligns to the end edge of the text direction.

```dream
End = 2
```

## `Justify`

Expands spacing to fill the paragraph width when applicable.

```dream
Justify = 3
```
