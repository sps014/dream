# system.gpu

Import `system.gpu` to run compute and render shaders written in Dream on the GPU, and to draw into `system.window` windows. Mark shader functions with `@compute`, `@vertex`, `@fragment` or the ray tracing stage attributes, choose their compile targets with `@gpu_targets`, and dispatch them through the generated `GpuShaders` class of each module.
