# JwtAlgorithm

**Import:** `import system.webapi.auth;`

## `JwtAlgorithm`

A supported JWT signature algorithm.

```dream
public enum JwtAlgorithm
```

## `RS256`

RSA signature using SHA-256 and PEM keys.

```dream
RS256
```

## `HS256`

HMAC using SHA-256 and a secret of at least 32 bytes.

```dream
HS256
```
