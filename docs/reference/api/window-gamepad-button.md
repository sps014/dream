# GamepadButton

**Import:** `import system.window;`

Read the [usage guide](../../library/system/window.md) for examples and common tasks. This reference lists the public declarations for this part of the library. See [Reading API signatures](index.md#reading-a-signature) for parameter and result notation.

## `GamepadButton`

A button on a standard-layout gamepad.  The four face buttons are named by position, so `South` is A on an Xbox controller and Cross on a PlayStation controller.

```dream
public enum GamepadButton
```

## `South`

The bottom face button (Xbox A, PlayStation Cross).

```dream
South = 0
```

## `East`

The right face button (Xbox B, PlayStation Circle).

```dream
East = 1
```

## `West`

The left face button (Xbox X, PlayStation Square).

```dream
West = 2
```

## `North`

The top face button (Xbox Y, PlayStation Triangle).

```dream
North = 3
```

## `LeftBumper`

The left shoulder button.

```dream
LeftBumper = 4
```

## `RightBumper`

The right shoulder button.

```dream
RightBumper = 5
```

## `Back`

The Back, View, Select or Share button.

```dream
Back = 6
```

## `Start`

The Start, Menu or Options button.

```dream
Start = 7
```

## `Guide`

The central logo button. Some browsers and operating systems keep it for themselves.

```dream
Guide = 8
```

## `LeftThumb`

Pressing the left stick.

```dream
LeftThumb = 9
```

## `RightThumb`

Pressing the right stick.

```dream
RightThumb = 10
```

## `DpadUp`

Up on the directional pad.

```dream
DpadUp = 11
```

## `DpadRight`

Right on the directional pad.

```dream
DpadRight = 12
```

## `DpadDown`

Down on the directional pad.

```dream
DpadDown = 13
```

## `DpadLeft`

Left on the directional pad.

```dream
DpadLeft = 14
```
