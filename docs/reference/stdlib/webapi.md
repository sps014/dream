# Native Web APIs

Import `system.webapi` to build an HTTP server from attributed functions. Routes,
parameter extraction, dependency injection, middleware and OpenAPI paths are
generated by `system.webapi.derive`, written in Dream. Serving requires the native
`dream-host-net` capability. Calls to server entry points in WebAssembly builds
produce a compile-time target diagnostic.

```dream
import system;
import system.webapi;
import system.json;

@json
class Greeting { public message: string; public constructor(message: string) { this.message = message; } }

@get("/hello/{name}")
fun hello(@path name: string): Greeting {
    return Greeting("Hello, " + name);
}

async fun main(): void {
    WebApp.run("127.0.0.1", 8000).await.unwrap();
}
```

## Routes and extraction

Use `@get`, `@post`, `@put`, `@patch`, `@delete`, `@head`, or `@options` with a
path. `@http_group("/api")` prefixes static route methods on a class. A parameter
whose name matches a `{segment}` binds that path segment; `@path("id")` overrides
the name. Missing bindings and duplicate routes are compile-time errors.

`@query`, `@header`, `@cookie`, and `@form` take an optional name override.
Scalar values are parsed; `Option<T>` accepts absence. Invalid or missing required
values return HTTP 400. `HttpIncoming` provides the method, encoded path, query,
headers, cookies and asynchronous `read_body_text` / `read_body_bytes` methods.

`@body` accepts `string`, `byte[]`, `JsonValue`, or an `@json` model. `@form` and
`@file` consume `multipart/form-data`; files bind `UploadedFile` (or
`Option<UploadedFile>`) with `filename`, `content_type`, and `bytes`. JSON bodies
and multipart extractors cannot be mixed. The host limits bodies to 16 MiB.

## Dependencies and middleware

`@dep(provider)` calls a dependency function and memoizes its value for that
request. Providers can receive extracted parameters, `HttpIncoming`,
`RequestContext`, and other dependencies. Cycles are compile-time errors.
`Result<T, HttpStatus>` failures short-circuit the request. `BearerToken`,
`ApiKeyHeader`, and `BasicAuth` provide header-based authentication dependencies.
`BasicAuth` returns the encoded credential text after `Basic `.

Middleware has the shape:

```dream
async fun authenticated(ctx: RequestContext, next: Next): HttpOutgoing {
    if ctx.incoming.header("Authorization").is_none() {
        return HttpOutgoing.from_status(HttpStatus.unauthorized());
    }
    return next.call().await;
}

@use(authenticated)
@get("/private")
fun private_page(): string { return "Welcome"; }
```

`@middleware(order)` installs global layers with lower orders outside higher
orders. `@use(handler)` is repeatable on routes and groups; group layers wrap
route layers. Runtime layers use `WebApp.use(Middleware(handler))`.
`RequestContext.state` is a per-request string map. Its `cancellation_token` is
cancelled on client disconnect.

Install CORS with `WebApp.use(CORS(CorsOptions()))`. Options control origins,
methods, allowed and exposed headers, credentials and preflight cache duration.
The middleware handles OPTIONS preflight and adds response headers.

## Responses and streams

Return `HttpOutgoing` for explicit status, headers, text or bytes. Factories
include `text`, `html`, `json_text`, `bytes`, `empty`, `detail`, and `from_status`.
A returned `string` becomes text; an `@json` model becomes JSON.
`Result<T, HttpStatus>` uses the error's status; `Result<T, string>` returns 500
with a JSON detail message. `HttpStatus` supplies common status helpers.

Yield events to stream server-sent events:

```dream
@get("/events")
async fun events(): AsyncIterable<SseEvent> {
    yield SseEvent.data("connected");
    Time.sleep(100).await;
    yield SseEvent("ready", Option.Some("update"), Option.Some("2"), Option.Some(1000));
}
```

`SseEvent` carries `data`, optional `event`, `id`, and `retry`. Newlines in data
become separate SSE data lines. `AsyncIterable<string>` and
`AsyncIterable<byte[]>` stream chunks; `@produces("content/type")` overrides the
content type. Synchronous `Iterable<T>` routes support the same element types.
Dispatch consumes streams incrementally with backpressure. Disconnect cancellation
stops the handler at a suspension point. There is no imperative EventStream API.

## WebSockets

```dream
@websocket("/ws")
async fun echo(ws: ServerWebSocket): void {
    await for (let message in ws.messages()) {
        switch (message) {
            Text(text) => { ws.send_text(text).await.unwrap(); },
            Binary(bytes) => { ws.send_binary(bytes).await.unwrap(); },
            Close(_, _) => {},
        }
    }
}
```

`ServerWebSocket` also offers `receive`, `close`, and `close_with`. All asynchronous
operations accept a trailing optional cancellation token and return `IoError`
failures. `messages()` includes the final Close message and ends on transport
failure. The shared `WebSocketMessage` union and client `WebSocket` live in
`system.net`; the client supports native, Node 22+ and browsers, using their
standard WebSocket facilities. Native clients support `ws://` and `wss://` with
certificate verification. Cancellation closes the owned socket.

## Lifecycle, TLS and documentation

`WebApp.listen` and `listen_with` return `Result<int, IoError>` containing the bound
port; port zero selects an ephemeral port. `run` and `run_with` listen and wait,
returning `Result<bool, IoError>`. `shutdown` stops the listener; `wait` awaits the
server loop. A trailing `token: Option<CancellationToken> = Option.None` uses an
explicit token or inherits the current structured task token.

`WebAppOptions` configures title, version, `docs_url` (default `/docs`),
`openapi_url` (`/openapi.json`), and `redoc_url` (`/redoc`). Empty URLs disable the
corresponding endpoint. Swagger UI and ReDoc load from CDNs. OpenAPI 3 describes
parameters, JSON models, multipart bodies and streaming content types.

For TLS, set both `tls_cert_path` and `tls_key_path` to PEM files. Supplying only
one, malformed credentials or a bind failure returns an `IoError`.
