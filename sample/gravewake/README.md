# Gravewake: Dustfall

An original low-poly zombie wave shooter written in Dream. Survive in a seasonal
canyon settlement with a quarry, trading stalls, ranger lookout, creek, bridge,
cabins, pines, cacti, broken carts and shelter clusters. Winter is the default. The walkable world spans 102 by 110 meters. All meshes and colors are generated by the sample's own code;
no downloaded characters, weapons, textures or environment packs are required.

Waves grow from six enemies to larger groups, introduce faster runners from wave
two, mix in fast infected hounds, and increase enemy health and speed. Hounds
use a quadruped gait and a close bite/lunge; they can be shot, staggered and killed
like the humanoid enemies. Deaths use articulated physics for both types: shot
and blast impulses drive constrained joints that collide with the floor and
world boxes. Bodies settle, leave snow drag marks and disappear after eight seconds. Up to twelve enemies are active at once;
remaining enemies enter as slots become free. There is no extraction objective or
final victory: try to beat your score before the horde catches you.

## Play

Build the compiler and native hosts once from the repository root:

```sh
cargo build --workspace
./target/debug/dreamer toolchain install slang
./target/debug/dream run --release sample/gravewake/main.dream
```

On Windows append `.exe` to executable names. From this sample directory,
`cargo run -- run --release` also builds and launches the game. Use a release build.
Startup, shader and GPU failures appear in the terminal.

Native desktop and WebGPU browsers are supported. Raster rendering is the default and
requires neither bindless materials nor ray queries. On devices reporting native
ray-query support, T lazily builds the static acceleration structure and toggles
static sun occlusion. Both modes use shared planar river reflections, scene-depth refraction and depth-dependent water absorption. Winter turns the creek into cracked ice. Raster mode already provides animated
2048-pixel sun shadow maps, including zombies and wind-driven foliage. RT retains
these moving shadows. Planar reflections include visible characters. Gameplay is
identical with RT off. Unsupported devices leave RT disabled. Execution on a non-RT GPU, Linux and macOS remains unverified.

## Browser

Build and serve from the repository root:

```sh
./target/debug/dream build --release --runtime --web sample/gravewake/main.dream
python -m http.server 8788 --directory sample/gravewake
```

Open <http://localhost:8788> in Chrome or Edge with WebGPU enabled. Click to capture
the mouse; Escape releases it and pauses. The launcher downloads the geometry
before starting and reports startup or GPU failures on the page. Browser rendering
uses the raster shadow map and planar creek reflections. Hardware RT stays native.
Clicking also unlocks browser audio: original synthesized gunshots, explosions,
hit impacts, reload sounds, enemy growls, footsteps and wind. Each weapon combines
a dry crack, a lower pressure impulse, mechanical action and a quieter tail;
small variations prevent every shot sounding identical. M toggles mute;
audio suspends when pointer capture is released or the page is hidden. These
sounds use no third-party recordings and need no external royalty license.
Native audio output is not implemented.

The original synthwave score runs at 108 BPM in F# minor. Pads, pulsing bass,
drums and arpeggios share an eight-bar progression. Wave number and the active
horde gradually add rhythmic and lead detail, capped at the later-wave arrangement;
intermissions ease the mix. Tempo stays fixed and the music ducks under shots
and explosions. M controls both effects and music. The score is synthesized
locally with no downloaded music or recordings.

The native-only ray-query shader omission warning during a web build is expected;
the browser never creates that pipeline.

## Seasons and snow

Press N to cycle winter, spring, summer and autumn. Winter covers the ground and
rooftops in snow, adds drifts and snowfall, and gives the creek an icy surface.
Boot and paw steps compress a persistent 1024-square height field. The snow mesh
sinks into these impressions, and its normals shade their edges. Bodies scrape
wider trails as they slide. Fresh powder slows movement; compressed paths are
faster, and camera and enemy foot height follow the local snow depth. Snowfall
gradually softens tracks. A bounded 384-event queue feeds the persistent field;
older impressions remain after their events leave the queue. Changing seasons
resets the field. This is a deformable surface rather than a volumetric snow simulation.

Spring has green terrain, summer restores the warm desert palette, and autumn
uses russet ground and warmer haze. Seasonal changes preserve the current wave.

## Image quality

All presets apply FXAA-style edge smoothing to the scene before drawing the HUD.
Press Q to cycle Low, Standard, High and Ultra. Play starts on High; press Q once
for Ultra. High renders at the drawable resolution, capped at 3840x2160. Ultra
renders at up to twice the drawable width and height, with the same 4K cap, then
downsamples to the window. At a 1920x1080 window, Ultra renders a 3840x2160 scene.
This costs more GPU work and memory. Standard stays capped at 960x540 and Low at
640x360, so both trade fine detail for lower rendering cost.

Text and crosshairs remain at display resolution. The flat polygon facets are
part of the art style; smoothing removes pixel stair steps without rounding the
actual geometry. The spatial filter uses no frame history and can still leave
some shimmer on very thin or reflective details during motion.

## Combat loop

- Aim high: rifle headshots deal double damage. The shotgun fires seven pellets
  with short range and strong recoil; reloads leave you exposed.
- The sniper has a five-round magazine, a magnified scope while holding right
  mouse, a bolt cycle between shots and a slower 2.7-second reload. Use it to
  remove dangerous targets before they close the distance.
- G throws a grenade. It bounces off cover and detonates after 2.3 seconds;
  blast damage respects walls and can hurt the player. Supplies and wave breaks
  replenish grenades. Its outward impulse throws defeated enemies into ragdolls.
- Chain kills within 3.5 seconds to increase your score multiplier, up to eight.
- F releases a charged shockwave within 7.5 meters. It damages and staggers nearby
  enemies, respects cover, and recharges from kills. Save it for an escape.
- C dashes in your movement direction, or forward while standing still. It has a
  3.5-second cooldown and a short melee dodge window; it cannot pass through walls.
- Orange barrels explode when shot. Lure groups into their 6.5-meter blast radius;
  neighboring barrels chain together. Cover blocks blast damage, and standing too
  close also hurts you. Barrels reset between waves.
- Gold caches in the quarry and orchard award 125 credits and 35 shockwave charge.
  Supplies are available in all three regions, so exploring has a practical reward.
- Kills also earn credits. Visit the orange supply totem near the starting path
  and press E to spend 150 credits on health and ammunition.
- Clearing a wave restores some health, ammunition and shockwave charge. During
  the nine-second break, choose Z for damage or X for movement speed. You get one
  choice each break. Pickups refresh for the next wave.

## Controls

| Input | Action |
| --- | --- |
| Click / Escape | Capture mouse and resume / pause and release |
| WASD / mouse / arrow keys | Move / look / turn |
| Left / right mouse | Fire / aim |
| 1 / 2 / 3 | Camp carbine / boomstick / bolt-action sniper |
| G | Throw a bouncing grenade with a 2.3-second fuse |
| M | Mute / unmute browser audio |
| R | Reload; restart after death |
| Shift / Ctrl / Space | Sprint / crouch / jump |
| F / C / E | Shockwave / dash / buy supplies near a totem |
| Z / X during wave break | Damage / movement upgrade |
| T / Q / F11 | RT toggle / resolution preset / fullscreen |

Focus loss pauses simulation. Click to resume. Horizontal rotation wraps without
limits; pitch is clamped. The simulation runs at 60 Hz with bounded catch-up.

## Rebuild the art

Install Blender 5 and Node, then prepare dependencies in the repository's ignored
build cache. Run these commands from the repository root:

```sh
npm install --prefix target/gravewake-assets three@0.180.0 three-mesh-bvh@0.9.2
blender --background --factory-startup --disable-autoexec --python sample/gravewake/tools/bake.py
node --max-old-space-size=8192 sample/gravewake/tools/pack.mjs
./target/debug/dream fmt sample/gravewake/src
./target/debug/dream build --release sample/gravewake/main.dream
```

Zombie geometry and 64-pose articulated clips are generated in `tools/zombie_art.py`.
Three baked proportions and outfits provide visual variety; hound geometry and
64 articulated poses come from `tools/dog_art.py`. Hit transitions blend
over 90 ms. Corpses settle to the ground, linger briefly, then sink before recycling.
`tools/world_art.py` emits collision for rails, pillars, trunks and fence supports
from the same placements as their visible geometry.

The bake requires Blender's bundled NumPy. All intermediate geometry, logs,
download archives from earlier development and captures stay outside the sample
in `target/gravewake-assets/`. Only runtime buffers and authoring data live under
`assets/`. Generation is deterministic with a fixed seed; it does not need a
Sketchfab credential or a network connection after tooling is installed.

## Focused validation

Build both targets and inspect gameplay in the browser. No new game test cases
are required for art, animation or level iteration. Sample-only changes do not
require compiler assertion corpora or workspace-wide gates.

```sh
./target/debug/dream build --release sample/gravewake/main.dream
./target/debug/dream build --release --web sample/gravewake/main.dream
python -B sample/gravewake/tools/benchmark_native.py --case high
```
